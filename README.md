# Trooper-Walk

A Three.js 3D character animation project built with Vite.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd 3d-project-server
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Download the main asset (REQUIRED):**
   Due to copyright terms, the 3D model is not included in this repository. Please follow these steps:
   * Access the model on [Sketchfab - Star Wars Imperial Stormtrooper](https://sketchfab.com/3d-models/star-wars-imperial-stormtrooper-tk-736n-rigged-c6c23e99a4eb4140a5e5eb709e77d866).
   * Download the **GLB** / **GLTF** file.
   * Paste the downloaded asset inside the `public/assets/` folder.
   * Rename the file exactly to: `imperial_stormtrooper.glb`

4. **Start the development server:**
   ```bash
   npm run dev
   ```
